# AHAT Benchmark v2.3.0 — 274-task release

Release date: 2026-11-13. This release freezes the corrected and pruned benchmark
at **274 active tasks: easy 117, medium 65, open 92**. It includes both the data
and the evaluation implementation, with versioned domains, validator and rubrics.

## Changes since the paper snapshot

- Correct task scenes, reference plans and goals; prune reviewed semantic
  overlap. Keep stable task IDs and document every migration and archive.
- Separate 244 ordinary-domain tasks from 30 liquid-domain tasks, with explicit
  liquid state and task-bound domain/rubric selection. Seven unsupported tasks
  remain quarantined outside the scored splits.
- Repair adjacency lifecycle, object/person locations, lighting, holding and
  placement capacity, and the PDDL type hierarchy. Nine active tasks explicitly
  require adjacency, including eight locally authored tasks.
- Clarify cooking, heating, food portions, meal preparation and stage order;
  repair dinner witnesses and distinguish required from optional adjacency in
  the four-dimensional rubric.
- Bind inference and evaluation to task domains and fingerprints, strengthen
  cache validation, and keep reference plans/goals out of inference exports.
- Apply the approved final 13-task easy pruning. Split versions are easy
  **1.11.0**, medium **1.10.0**, open **1.10.4**.

## Validation and use

The frozen dataset passes 117 offline tests, all 274 native VAL reference plans,
17 annotated goals, nine adjacency controls and four thermal-processing controls.
Both domains and all 274 problems parse independently; 4,107 scene/PDDL replay
steps agree with no dropped initial facts. Evidence is linked from
[easy-pruning-v1](../easy-pruning.md); release packaging checks are recorded in
[the release report](../validation/release_v2.3.0_checks.json).

Install with Python 3.10+ on Linux x86-64 (glibc 2.34+ and GLIBCXX_3.4.29), then
run `ahat-benchmark doctor`. Release assets include the source distribution,
a Linux x86-64 wheel and SHA-256 checksums. Code is MIT; task data remain
CC BY-NC 4.0; bundled third-party components retain their own licenses.

No model scores are claimed for this 274-task release. The previous 287-task
GPT/DS evaluation remains a historical experiment. Use fresh output directories
and report this tag, dataset/domain/prompt hashes and model configuration for
new evaluations. VAL legality and offline goal checks do not establish natural
language task success for every possible plan; the four-dimensional judge
remains part of runtime evaluation.
