## 本轮发现并修复的重测入口问题

`scripts/generate_inference.py` 原来只读全局普通 domain，且结果不写任务 domain
ID/hash。液体任务会得到错误动作表，其输出也无法满足正式评测的绑定检查。
现在按每道任务的绑定加载 domain，并在每条结果中保存 ID/hash；混合普通／液体的
模拟 API 请求、结果加载和真实 VAL 回归通过。未调用真实模型或裁判。

这个脚本是一次请求生成整条 plan 的示例，**不是历史逐步 Direct**。不要将它的成绩
冒称历史 Direct 的复测。历史外部 `run_openai_direct348.py` 仍硬编码 348 道任务、
一个共享 domain 和旧冻结数据；不能原样启动当前 287 题混合 domain 测试。
正式重测需要基于新输入适配／选择逐步入口，并验证每步动作与当前 domain 一致。

## 仍保留的限制

按用户既定决定暂缓的三项模型问题仍未修复：

1. 外层关闭容器的通用可访问性约束不完整。
2. 扩展液体组合可能破坏 scene 不变量（例如同杯先泡面再泡茶）。
3. on/in 空间关系缺少通用防环约束。

当前正式参考未触发，不保证 GPT 生成的其他计划不触发。出现时应单独登记模型漏洞或
转换故障，不能混同正常模型失误。D1 仅看末态，D3/D4 提供前序与顺序证据，但它们
仍是 LLM rubric，没有硬性的历史阶段成功门槛。份量、连续温度、营养和主观品质也仍
采用已声明的抽象；不应把这些限制报成全部已修复。
